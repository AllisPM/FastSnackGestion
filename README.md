# FastSnackGestion
# Descripción del proyecto
AppFastSnack es un sistema desarrollado en Java con conexión a MySQL que permite gestionar los pedidos de un negocio de comida rápida. El sistema cuenta con una interfaz gráfica que facilita el registro y administración de los pedidos y de los productos asociados a cada uno, permitiendo organizar la información de manera eficiente y mejorar la atención al cliente.

# Instrucciones de instalación y ejecución
Descargar o clonar el repositorio del proyecto desde GitHub. Abrir el proyecto AppFastSnack en Apache NetBeans. Importar la base de datos MySQL utilizando el script .sql incluido en el repositorio. Verificar que los datos de conexión a la base de datos sean correctos. Ejecutar el proyecto desde NetBeans. Ingresar al sistema mediante la ventana de inicio y utilizar las diferentes opciones disponibles para gestionar los pedidos y los productos registrados.

#Tecnologías utilizadas
- Java Java Swing (JFrame)
- MySQL Apache NetBeans Maven GitHub Chat GPT
